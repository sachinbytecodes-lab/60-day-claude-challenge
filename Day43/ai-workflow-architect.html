Workflow Summary

This build sequence takes a portfolio from a blank repo to a deployed, discoverable site in six sheets: plan the content and audience, write the copy, design the interface, build it with AI-assisted code, test across devices, then ship and keep it growing. Each sheet is independent enough to revisit — treat this as a living document, not a one-time checklist.
