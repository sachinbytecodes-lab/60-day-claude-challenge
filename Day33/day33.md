# 📖 Overview

**Media Integrity Analyzer** is a premium editorial-style interactive web application built entirely using **HTML, CSS, and JavaScript**.

The application teaches **media literacy** through **interactive learning**, allowing users to discover manipulation techniques themselves rather than simply reading definitions.

Instead of testing knowledge, the application guides users through realistic fictional media examples and gradually reveals how misleading headlines, emotional framing, audience targeting, and manipulation techniques work.

Everything runs **100% offline** inside **one HTML file** with **zero dependencies**.

---

# 🎯 Project Objective

The objective of this project is to help users:

- Identify misleading headlines
- Recognize emotional manipulation
- Understand audience targeting
- Learn responsible media consumption
- Build practical media literacy habits

Rather than memorizing theory, users **learn by interacting** with fictional news articles and social media posts.

## 📚 Guided Learning Experience

Instead of immediately asking questions, every challenge first explains:

- What the concept means
- Why it matters
- Where people encounter it in real life
- How manipulation works

This creates a genuine learning experience rather than a quiz.

---

## 📰 Challenge 1 — Headline Detective

Users analyze a fictional news article.

They can:

- Read the headline
- Read the article
- Decide whether they would click
- Identify exaggerated wording
- Reveal the complete analysis

The application then explains:

- Headline Accuracy Score
- Highlighted misleading phrases
- Why the headline is misleading
- Fair rewritten headline
- Practical takeaway

---

## ❤️ Challenge 2 — Emotion Detector

Users inspect a fictional social media post.

They interactively:

- Select how the post made them feel
- Choose emotionally loaded words
- Reveal the emotional manipulation analysis

The application explains:

- Target audience
- Intended emotional response
- Manipulation technique
- Emotional trigger phrases
- Neutral rewrite
- Practical takeaway

---

## 📊 Live Media Integrity Metrics

During the lesson the dashboard updates in real time.

Metrics include:

- Headline Accuracy
- Source Reliability
- Emotional Manipulation
- Audience Targeting

These metrics visually reinforce how different manipulation techniques affect media integrity.

---

## 📈 Final Media Integrity Dashboard

At the end of the lesson users receive a complete summary including:

- Overall Media Integrity Score
- Lesson summary
- Biggest manipulation red flag
- Three lifelong media literacy habits
- Replay with completely new fictional scenarios
