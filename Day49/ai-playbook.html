What is the AI Playbook?

This is a personal toolkit for writing better prompts for coding work — built around how you actually use AI: debugging tricky errors, reviewing code, writing tests, and running autonomous agent loops. It's not a prompt library to scroll through; it's a set of reusable building blocks you combine into exactly the prompt you need, every time.

Workflows — ready-made prompt templates for your recurring dev tasks, with editable variables Prompt Builder — assemble a one-off prompt from parts (role, context, constraints, etc.) with a live preview Loop Builder — turn any prompt into a self-checking, autonomous agent loop with stop conditions

Loop Builder

An autonomous loop is a prompt that tells the AI to keep working, self-check its own output, and only stop once specific conditions are met — useful for agentic tools like Claude Code that can run multiple steps unattended. Fill in each part below.

The single task you want repeated and refined — e.g. "Fix the failing tests in this repo."
What "done" looks like — the concrete target the loop is working toward.
How the AI should judge its own output after each attempt, before deciding to continue.
What the AI should do differently if the first attempt doesn't meet the goal.
Explicit rules for when the loop must stop — success, failure, or a safety limit.
Guardrails so the agent doesn't do something risky while iterating unattended.
