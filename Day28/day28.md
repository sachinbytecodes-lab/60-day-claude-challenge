# 📖 Project Overview

This project simulates the complete **Hospital Admission Readiness Process**, allowing users to experience how hospitals evaluate patient admission readiness before approving an inpatient admission.

The simulator includes:

- Patient Admission Setup
- Clinical & Provider Information
- Prior Authorization Workflow
- Readiness Score Calculation
- Risk Analysis
- Admission Timeline
- Care Coordination
- Governance Dashboard
- Final Admission Decision

The application was generated as a **single-page HTML application** and functions completely in the browser without any backend.
