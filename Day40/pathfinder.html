How this was built

System prompt design, UI decisions, and extension ideas
▼

Who this is for

Recent grads / early-career people who feel directionless. The single goal of one session: leave with 2–4 concrete career path recommendations, each with clear reasoning, so they feel oriented and confident enough to take a next step — not just "explored options."

System prompt design

The assistant is instructed to run a guided, adaptive interview rather than a static form — it asks one focused question at a time (interests, natural strengths, energizing vs draining tasks, constraints like location/money/timeline, and what they've already tried or ruled out), and adapts follow-ups based on what the user says. It's told explicitly not to move to recommendations until it has enough signal, but also not to interrogate endlessly — a hard cap keeps it to roughly 4–6 exchanges before it must synthesize.

The output format is a structured recommendation with reasoning: 2–4 named career paths, each with a one-line "why this fits you" tied directly back to something the user said, a realistic first step, and an honest note on the tradeoff or challenge of that path. The tone directive is blunt/expert — no hedging, no "there's no wrong choice!" platitudes, no therapy-speak. It's told to disagree with the user if their stated plan conflicts with what they've described about themselves.

Edge cases handled in the prompt: users who overshare trauma/mental health struggles (redirect gently to career focus, don't diagnose), users who want to skip the interview and get instant answers (comply but flag that recommendations will be generic), users asking for something outside career scope (redirect firmly), and users who push back on a recommendation (engage with the specific objection rather than backpedaling to please them).

UI decisions

  • Conversational chat interface matches the "guided multi-turn" input mode — no rigid form fields that would fight against adaptive follow-ups.
  • Quick-start chips lower the blank-page barrier for users who don't know how to begin describing themselves.
  • Path cards render inside assistant messages (parsed from a lightweight [PATH]title|why[/PATH] marker convention) so final recommendations feel scannable and distinct from regular chat text, not just another paragraph.
  • Dark, editorial color palette (near-black + warm orange/amber accent) signals "expert career coach," not "cute chatbot."
  • API key is requested client-side and kept only in page memory (a let variable, never localStorage) — appropriate for a demo/prototype single-file app.

Future extensions

  • Tools: connect a live job-market/salary-data API so recommendations cite real demand and pay ranges instead of general knowledge; add a resume-parsing tool so the interview can start from an uploaded resume instead of pure conversation.
  • Memory: persist a user profile across sessions (skills, ruled-out paths, past recommendations) so returning users get "since we last talked, has anything changed?" instead of restarting the interview from zero.
  • Multi-step workflow: after recommendations, offer a follow-on flow that turns the top path into a 30-day action plan, generates outreach message drafts for informational interviews, or hands off into a resume-tailoring assistant for that specific path.
  • Export: let users download their recommendation summary as a shareable one-page PDF.
