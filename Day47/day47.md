# 📖 Overview

**Content Intelligence Studio** is a premium AI-powered web application that analyzes digital content using multiple specialized AI reviewers.

Instead of relying on rule-based logic or hardcoded feedback, the application dynamically creates an intelligent review workflow and sends every analysis request to the **Claude Messages API**.

The application supports both **text** and **image uploads**, allowing AI to evaluate:

- Social media posts
- Blog articles
- Video thumbnails
- Screenshots
- Captions
- Marketing content

Every score, recommendation, rewrite, and explanation is generated live by AI.

---

# 🎯 Project Objective

The goal of this project is to build a professional AI content consultant capable of:

- Understanding uploaded content
- Designing an intelligent review pipeline
- Running multiple AI experts
- Producing actionable recommendations
- Rewriting content
- Predicting content performance
- Delivering a comprehensive final report
