# 🏥 Prior Authorization Workflow Simulator

> **Day 26 – ABTalks 60 Days Challenge**

A fully interactive **Prior Authorization (PA) Workflow Simulator** built using **HTML, CSS, and JavaScript** that demonstrates how the **U.S. Healthcare Prior Authorization process** works from patient intake to the final insurance decision.

The simulator allows users to experience the real-world workflow followed by healthcare providers, insurance companies, and patients while learning each stage of the authorization process through interactive scenarios.

---

# 📌 Project Overview

Prior Authorization (PA) is a process used by health insurance companies to determine whether they will cover a prescribed procedure, medication, imaging study, or treatment before it is provided.

This simulator recreates the complete workflow using an interactive drag-and-drop interface where users progress a patient through different stages including:

- Patient Intake
- Medical Necessity Evaluation
- Document Collection
- Submission to Insurance
- Insurance Review
- Approval / Denial / Pend
- Appeal / Peer-to-Peer Review
- Final Decision

The application also provides educational information throughout the workflow to help understand the business logic behind each step.
