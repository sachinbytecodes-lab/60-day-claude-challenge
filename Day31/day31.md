# 📖 Project Overview

**AI Supply Chain Control Tower** is a fully interactive browser-based simulation that places the player in the role of a **Head of Operations** responsible for managing a global supply chain.

During the simulation, unexpected operational disruptions continuously occur across suppliers, factories, ports, warehouses, transportation networks, and logistics operations.

The objective is to:

- Prioritize operational alerts
- Make strategic business decisions
- Protect revenue
- Maintain customer satisfaction
- Improve operational KPIs
- Achieve the highest performance score before time expires

The complete application is developed inside **a single HTML file** using only:

- HTML
- CSS
- Vanilla JavaScript

No frameworks, libraries, APIs, or backend services are used.

The application works completely **offline**.

## 🚨 Operational Alerts

Random alerts include:

- 🚢 Port Congestion
- 🏭 Supplier Delay
- 🚛 Truck Breakdown
- 📦 Warehouse Running Out of Stock
- 🛃 Customs Inspection
- 📈 Demand Spike
- ⚙️ Factory Machine Failure
- 🌪 Weather Disruption
- 🔢 Wrong Inventory Count
- 📦 Damaged Shipment

Each alert contains:

- Title
- Description
- Priority
- Countdown Timer
- Business Impact
- Multiple Decision Options

## 🧠 Decision System

Each alert provides different actions, including:

- Expedite Shipment
- Use Backup Supplier
- Increase Production
- Transfer Inventory
- Reroute Trucks
- Approve Air Freight
- Delay Decision
- Ignore

Every decision has different business consequences.
