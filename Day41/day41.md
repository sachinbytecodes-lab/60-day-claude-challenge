# 📖 About The Project

This project was developed as part of the **AB Talks 60 Days Challenge (Day 41)**.

The objective was to design and develop a **fully interactive educational web application** using only **HTML, CSS, and JavaScript**, without relying on any external libraries or frameworks.

Instead of building a simple webpage, I created a complete **Interactive Learning Studio** inspired by platforms like **Codecademy, Coursera, and DataCamp**, where users can learn Python Object-Oriented Programming in a structured and engaging way.

The application combines premium UI design with interactive educational content, allowing learners to study concepts, solve exercises, attempt quizzes, unlock modules, and track their learning progress—all within a single self-contained HTML file.
